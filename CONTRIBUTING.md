# Contributing

Thanks for your interest in improving this project!

## Getting Started

```bash
git clone https://github.com/AlphaCortex-03/Jupiter-Notebook.git
cd Jupiter-Notebook
pip install -r requirements.txt
```

## Making Changes

1. Create a branch for your change
2. Make your edits
3. Run the notebook or script to verify outputs
4. Commit with a clear message
5. Push and open a pull request

## Code Style

- Python: follow PEP 8
- Keep notebooks clean and well-commented
- Use relative paths for all file operations

## Pull Requests

- Explain what changed and why
- Include screenshots or output diffs for visual changes
- Reference any related issues
